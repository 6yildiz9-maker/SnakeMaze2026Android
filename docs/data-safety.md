# Google Play Data Safety Declaration — Snake Maze 2026

## Data Collection & Sharing Summary
- **Data shared with 3rd parties:** Device or other IDs (AdMob Advertising ID, for rewarded ads).
- **Data collected:** Device or other IDs (Advertising ID).
- **Security practices:** Data in transit is encrypted over standard HTTPS.
- **Data retention:** Local game statistics remain on the user's device and can be cleared via Application Data Settings or in-game reset.
