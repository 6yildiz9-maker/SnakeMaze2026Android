# Google Play Data Safety Declaration — Snake Maze 2026

## Working declaration — verify in Play Console before publishing

- **Third-party SDK:** Google Mobile Ads (AdMob), Android version only.
- **Data AdMob may collect/share:** Advertising or other device identifiers, IP address (including approximate location inference), ad interactions, and diagnostics. Review the current Google Mobile Ads SDK disclosure and the app's SDK version in Play Console before answering the Data safety form.
- **Game data:** Scores, settings, achievements, and custom mazes are stored locally in Android Preferences; the developer does not operate a game-data account or upload service.
- **Encryption:** Ad requests use Google's SDK/network transport; confirm the current SDK disclosures in Play Console rather than treating this note as a legal determination.
- **Deletion:** Local game data can be removed by clearing the app's storage in Android settings. The app currently has no cloud account or server-side game-data deletion flow.
- **Consent:** Google UMP requests consent before Android ads when required; the app exposes Ad Privacy Options in Settings.

The Play Console Data safety answers must be confirmed against the AdMob account's configured messages and Google's current SDK disclosures. This working file is not a substitute for that declaration.
